# Satu VPS atau cloud di Indonesia dengan backup harian di lokasi lain

Sistem berjalan di satu instans (VPS atau cloud) yang berlokasi di Indonesia, dengan backup tiap 24 jam ke object storage di lokasi berbeda. Data Siswa adalah data anak sehingga residensi data (UU PDP) menjadi batasan. Skala (50+ pengguna bersamaan, ketersediaan 99%) tidak membenarkan klaster atau on-premise.
