# Tutor menginput Absensi dan Nilai, terkunci 24 jam, Koreksi hanya Admin

Software Request menyatakan "data hanya dapat diubah oleh administrator sistem", tetapi Absensi dan Nilai diinput tiap sesi sehingga Admin tidak mungkin menjadi satu-satunya penginput. Keputusan: Tutor menulis data Kelasnya sendiri, Sesi terkunci otomatis 24 jam setelah selesai, dan sesudahnya hanya Admin yang boleh mengoreksi dengan catatan audit (pelaku, waktu, nilai lama dan baru). Ini penafsiran sengaja atas persyaratan keamanan tersebut.
