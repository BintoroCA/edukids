# Levelling per Siswa per Mata Pelajaran, bukan per Kelas

Perhitungan Level dan Rekomendasi Kenaikan memakai seluruh riwayat Siswa pada satu Mata Pelajaran, terlepas dari Kelas tempat Nilai dan Absensi dicatat. Dengan begitu pindah Kelas tidak mengulang atau menghilangkan progres. Konsekuensinya, riwayat Absensi dan Nilai tidak boleh dihapus saat Siswa pindah Kelas.
