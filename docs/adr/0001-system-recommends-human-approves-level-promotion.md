# Sistem merekomendasikan kenaikan Level, manusia menyetujui

Sistem menghitung Rekomendasi Kenaikan dari rata-rata Nilai dan kehadiran, tetapi Level hanya berubah setelah Persetujuan Kenaikan oleh Admin atau Tutor. Alternatif kenaikan otomatis ditolak: aturan ambang batas tidak menangkap konteks per anak, dan kepercayaan Orang Tua bergantung pada keputusan yang bisa dipertanggungjawabkan oleh orang.
